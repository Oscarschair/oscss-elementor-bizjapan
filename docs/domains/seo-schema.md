# SEO & 構造化データ設計書 (SEO & Structured Data Specification)

## 1. メタ情報設計方針

香港検索市場（Google HK: `google.com.hk`）での検索順位向上とクリック率（CTR）最大化を図るため、以下のメタタグを適用しています。

### 1.1 基本タグ
| タグ | 出力値 | 役割・効果 |
| :--- | :--- | :--- |
| `html lang` | `zh-HK` | 香港向け繁体字文書であることを明示。検索エンジンによる地域適合性判定を最適化。 |
| `<title>` | `日本設立公司・商業代辦服務｜助香港企業一站式進軍日本市場｜OSCAR` | 「日本設立公司」「商業代辦」「香港企業」の重要キーワードを先頭に配置。 |
| `<meta name="description">` | `【香港企業專屬】專業代辦日本公司註冊、經營管理簽證、.jp域名申請及日本多言語網站製作。即使身在香港、非日本居民亦能順利在日設立「株式會社」。更可配合香港政府BUD專項基金及EMF資助，助您半價拓展日本業務。立即免費諮詢！` | 検索結果スニペットで強み（非居住者OK、助成金半額）を伝えCTRを高める。 |
| `og:locale` | `zh_HK` | Facebook / LinkedIn / WhatsApp 共有時の言語地域指定。 |

## 2. 構造化データ (JSON-LD) 設計

Google 検索結果でのリッチリザルト表示（サービス情報、FAQカルーセル）を獲得するため、`Schema.org` 規格の JSON-LD を `wp_head` から自動出力しています。

### 2.1 Service スキーマ
- **対象**:
  1. 代辦設立日本公司 (Company Incorporation)
  2. 代辦取得日本.jp專屬域名 (Domain Registration)
  3. 建立日本本地化官方網站 (Web Development)
- **対象地域 (areaServed)**: `Hong Kong`, `Japan`
- **提供者 (provider)**: `商業代辦服務 by OSCAR`

### 2.2 FAQPage スキーマ
検索結果に折りたたみ式のQ&Aを表示させ、検索画面の専有面積を拡大します。

1. **Q: 身在香港、沒有日本在留資格可以設立日本公司嗎？**
   - A: 可以。日本法規允許全體代表董事皆為非日本居民，身在香港亦能合法登記註冊「株式會社」。
2. **Q: 設立日本公司時，沒有日本地址怎麼辦？**
   - A: 提供合規的日本虛擬辦公室或實體事務所地址租賃方案。
3. **Q: 香港人可以在日本買樓置業嗎？**
   - A: 可以。外國人購置日本房地產無身分限制，擁有永久產權。
4. **Q: 如何透過設立公司申請日本「經營・管理」簽證？**
   - A: 具備實體辦公室、500萬日圓以上資本金及商業計劃書，由專業行政書士協助辦理。
