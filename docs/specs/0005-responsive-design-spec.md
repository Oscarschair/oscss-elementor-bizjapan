# SPEC-0005: マルチデバイス完全レスポンシブデザイン仕様書

- **ステータス**: 承認済 (Accepted)
- **対象**: 全ページ（トップページ、`/contact-us/`、固定ページ、アーカイブ）
- **対象画面幅**: 
  - スマートフォン (SP): 375px 〜 414px (および 320px 最小幅)
  - タブレット (Tablet): 768px 〜 1024px
  - デスクトップ (PC): 1280px 以上
- **担当**: OSCSS 開発チーム

---

## 1. 概要 & 背景 (Overview & Background)

本サイトは、香港のスマートフォン利用率の高さを背景に、訪問者の7割以上がモバイル端末からの閲覧であることが想定されている。
従来のデスクトップ中心の固定指定（`font-size: 34pt`, `24pt`、横並び固定Flex等）では、スマホ幅において以下の問題が発生していた：
1. **横スクロール・要素のはみ出し**: 画面外へコンテンツが突出し、横揺れ・横スクロールが発生する。
2. **見出しフォントの過大表示**: 34pt の見出しがスマホ画面で過度に巨大になり、不自然な改行や見切れを起こす。
3. **カードやコンテンツの圧迫**: 複数列の横並び要素がスマホ幅で狭小化・テキストが潰れる。
4. **タップ領域の不足**: リンクやボタンが指で押しにくい。

本仕様では、すべてのブレークポイントで流麗（Fluid）かつ直感的に操作できるマルチデバイス・レスポンシブUIを定義する。

---

## 2. ユーザーストーリー (User Stories)

- **US-1 (モバイル訪問者)**:
  - **AS A** iPhone / Android 等のスマートフォンで閲覧するユーザー
  - **I WANT TO** 横スクロールや文字化け・見切れがなく、読みやすいフォントサイズと綺麗な縦積みカードで情報を見たい
  - **SO THAT** ストレスなく素早く事業内容を理解できる。

- **US-2 (タブレット訪問者)**:
  - **AS A** iPad / Android タブレットで閲覧するビジネスユーザー
  - **I WANT TO** 画面幅を活かした2カラムのグリッドで効率よくサービス一覧を比較したい
  - **SO THAT** 大画面とモバイルの双方の利点を享受できる。

---

## 3. 受入条件 (Acceptance Criteria: Given-When-Then)

### AC-1: 横スクロールの完全遮断 (Horizontal Overflow Prevention)
- **Given**: 幅 320px, 375px, 390px, 414px の実機またはブラウザエミュレータ
- **When**: ページ全体を上下にスクロールした時
- **Then**: 左右の横スクロールバーが一切発生せず、全コンテンツが画面幅内に収まること（`overflow-x: hidden`）。

### AC-2: 流動的フォントサイズ (Fluid Typography)
- **Given**: スマホ画面幅（<= 767px）
- **When**: H1, H2, H3 等の見出しが表示された時
- **Then**:
  - H1 は `clamp(24px, 6.5vw, 32px)` で描画され、一行ごとの単語の途中で不自然な折り返しが起きないこと。
  - セクション見出し（H2）は `clamp(20px, 5.5vw, 26px)` で描画されること。
  - 本文は 15px〜16px で可読性が担保されること。

### AC-3: コンテナ・カードのレスポンシブスタック
- **Given**: スマホ画面幅（<= 767px）
- **When**: 「服務內容」「你知道嗎」「其他資訊（BUD/EMF）」セクションを閲覧した時
- **Then**:
  - すべてのカード・ボックスが 1カラム（縦積み 100% 幅）に変換されること。
  - 画像は幅 100%、高さ 180px（`object-fit: cover`）でトリミングされ、歪みなく表示されること。

### AC-4: タブレット最適化 (768px 〜 1024px)
- **Given**: タブレット画面幅（768px 〜 1024px）
- **When**: 「服務內容」「你知道嗎」「其他資訊」を閲覧した時
- **Then**: 2カラムのバランスの取れたグリッドレイアウトで整列表示されること。

### AC-5: ボタン・CTAのタップ領域
- **Given**: タッチデバイス（モバイル・タブレット）
- **When**: ボタンやCTAリンクをタップした時
- **Then**: WCAG 2.1 基準に準拠した最小タップ領域（48px × 160px 以上）が確保され、誤タップなく快適に反応すること。
