# SPEC-0004: 自社製お問い合わせフォーム及びメール通知 (contact@oscarchair.jp) 仕様書

- **ステータス**: 承認済 (Accepted)
- **対象ページ**: `https://bizjapan.oscarchair.jp/contact-us/`
- **通知先**: `contact@oscarchair.jp`
- **担当**: OSCSS 開発チーム

---

## 1. 概要 & 背景 (Overview & Background)

現在 `/contact-us/` には Google フォームの `iframe` が埋め込まれているが、以下の課題がある：
1. **UI/UX の不整合**: Google フォームの枠線やデザインがサイト全体のデザイン・青系カラーと馴染まない。
2. **通知の遅延・確認漏れ**: Google スプレッドシートや別画面を確認する必要があり、迅速な顧客対応が難しい。
3. **モバイル操作性**: スマホ幅でスクロールバーが二重に発生し、離脱原因となっている。

本仕様では、Google フォームを廃止し、サイトのデザイン（メインカラー：青）に完全に調和した自社製Webフォームを導入し、送信時に即座に `contact@oscarchair.jp` へメール通知が届く仕組みを構築する。

---

## 2. ユーザーストーリー (User Stories)

- **US-1 (サイト訪問者)**:
  - **AS A** 日本進出代行サービスに興味を持った香港の顧客
  - **I WANT TO** 洗練されたフォームから、社名・連絡先・希望サービスを迷わずスムーズに入力・送信したい
  - **SO THAT** 送信完了が明確にわかり、安心して返信を待つことができる。

- **US-2 (OSCAR 運営チーム)**:
  - **AS A** お問い合わせ対応スタッフ
  - **I WANT TO** 顧客がフォーム送信した瞬間に、`contact@oscarchair.jp` で詳細な問い合わせ内容を受信したい
  - **SO THAT** 1営業日以内のスピーディーな初動対応が可能になる。

---

## 3. フォーム入力項目仕様 (zh-HK)

| 項目名 (zh-HK) | 入力タイプ | 必須 | バリデーション / 備考 |
| :--- | :--- | :--- | :--- |
| **姓名 / 聯絡人** | text | 必須 | 氏名 |
| **公司名稱** | text | 任意 | 法人名または屋号 |
| **電郵地址** | email | 必須 | メールアドレス形式チェック |
| **聯絡電話 / WhatsApp** | tel | 必須 | 電話番号またはWhatsApp番号 |
| **諮詢服務類別** | select | 必須 | 選択肢（会社設立、.jpドメイン、日語Web制作、ビザ、置業、助成金、その他） |
| **諮詢內容 / 留言** | textarea | 必須 | 自由記述（最大2000文字） |
| **スパム対策** | honeypot & nonce | - | 一般ユーザーには不可視、ボット入力時に送信拒否 |

## 4. メール通知仕様 (`wp_mail`)

### 4.1 管理者宛て通知メール
- **宛先**: `contact@oscarchair.jp`
- **送信元 (From)**: `商業代辦服務 by OSCAR <no-reply@bizjapan.oscarchair.jp>` (またはサイトデフォルト)
- **Reply-To**: ユーザーが入力したメールアドレス
- **件名**: `【商業代辦服務 by OSCAR】網站收到新的商業諮詢表格（[姓名] 様）`
- **本文構成**:
  ```text
  【商業代辦服務 by OSCAR】網站收到新的商業諮詢表格。
  詳細資料如下：
  --------------------------------------------------
  ■ 諮詢時間: YYYY-MM-DD HH:MM:SS
  ■ 姓名 / 聯絡人: [姓名]
  ■ 公司名稱: [公司名稱]
  ■ 電郵地址: [電郵地址]
  ■ 聯絡電話 / WhatsApp: [聯絡電話]
  ■ 諮詢服務類別: [服務類別]
  --------------------------------------------------
  ■ 諮詢內容:
  [諮詢內容]
  --------------------------------------------------
  ※ 回覆此郵件可直接發送至客戶電郵地址。
  ```

### 4.2 お客様宛て自動返信メール (zh-HK)
- **宛先**: ユーザーが入力したメールアドレス
- **件名**: `【商業代辦服務 by OSCAR】已收到閣下的商業諮詢登記`
- **本文**: 香港標準書面語にて、受付完了と1-2営業日以内の連絡予定を明記。
