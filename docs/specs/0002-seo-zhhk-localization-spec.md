# SPEC-0002: SEO最適化・香港標準書面語 (zh-HK) ローカライズ及びモバイルCTA仕様書

- **ステータス**: 承認済 (Accepted)
- **対象**: `bizjapan.oscarchair.jp` トップページおよびサイト全体
- **担当**: OSCSS 開発チーム

---

## 1. 概要 & ビジネス背景 (Overview & Background)

### 1.1 課題と目的
本サイト（`bizjapan.oscarchair.jp`）は、香港の中小企業経営者・投資家向けに日本法人設立や日本市場進出代行サービスを提供するLP型Webサイトである。
従来の構成では、HTMLの言語設定が台湾繁体字（`zh-TW`）となっており、香港特有のビジネス表現（「註冊」「閣下」等）と一部乖離があったほか、検索エンジン最適化（SEO）におけるタイトル・メタディスクリプション・構造化データ（JSON-LD）が不十分であった。
本仕様では、香港標準書面語（zh-HK）への完全適合、Google検索における上位表示およびリッチリザルト獲得、そしてスマホ訪問者のコンバージョン率（CVR）最大化を目的とした仕様を定義する。

---

## 2. ユーザーストーリー (User Stories)

- **US-1 (香港の起業家・経営者)**:
  - **AS A** 日本進出を検討している香港の経営者
  - **I WANT TO** 違和感のない自然な香港繁体字（zh-HK）で、非居住者の会社設立可否や手続きの流れを素早く理解したい
  - **SO THAT** 信頼できるパートナーであると判断し、気軽に相談できる。

- **US-2 (モバイル閲覧ユーザー)**:
  - **AS A** スマートフォンでサイトを閲覧している多忙なビジネスパーソン
  - **I WANT TO** 画面下部に常時表示される WhatsApp や問い合わせボタンから、1タップで即座に相談を開始したい
  - **SO THAT** 問い合わせフォームを探すストレスなく、スピーディーに連絡を取ることができる。

- **US-3 (マーケター / SEO担当者)**:
  - **AS A** サイトの集客担当者
  - **I WANT TO** 香港のGoogle検索（google.com.hk）において「日本設立公司」「代辦日本公司」等の主要キーワードで上位表示され、検索結果にFAQリッチリザルトが表示されるようにしたい
  - **SO THAT** 広告費に過度に依存せず、オーガニック検索からの良質なリードを継続的に獲得できる。

## 3. 機能要件と受入条件 (Acceptance Criteria: Given-When-Then)

### AC-1: 言語属性とOGPの香港統一
- **Given**: ユーザーまたは検索エンジンクローラーがサイトの任意のページにアクセスした時
- **When**: HTMLのヘッダー情報および `<html>` タグを読み込んだ時
- **Then**: 
  - `<html>` タグに `lang="zh-HK"` が出力されていること。
  - OGPメタタグ `og:locale` に `zh_HK` が出力されていること。

### AC-2: SEOタイトル & メタディスクリプション
- **Given**: トップページ（Front Page）が表示された時
- **When**: `<head>` タグ内の `<title>` および `<meta name="description">` を取得した時
- **Then**:
  - タイトルが `日本設立公司・商業代辦服務｜助香港企業一站式進軍日本市場｜OSCAR` であること。
  - ディスクリプションに「香港企業專屬」「日本公司註冊」「經營管理簽證」「BUD專項基金」が含まれていること。

### AC-3: 構造化データ (JSON-LD) の出力
- **Given**: トップページ（Front Page）が表示された時
- **When**: Google リッチリザルトテストまたはスキーマバリデータで検証した時
- **Then**:
  - `Service` スキーマ（会社設立代行、.jpドメイン取得、Web制作）が正常に出力されていること。
  - `FAQPage` スキーマ（代表取締役が非居住者でも設立可能か、住所要件、置業、経営管理ビザ等）が出力され、エラー・警告がないこと。

### AC-4: モバイル固定コンバージョンバー (Sticky Bar)
- **Given**: 画面幅 767px 以下のモバイル端末でサイトを閲覧している時
- **When**: ページをスクロールした時
- **Then**:
  - 画面最下部に「💬 WhatsApp 查詢」および「✉️ 免費諮詢」のボタンバーが固定表示されること。
  - ページ最下部のフッター情報が固定バーで隠れないよう、適切な `padding-bottom` が確保されていること。
  - 画面幅 768px 以上のPC・タブレット表示時は固定バーが非表示（`display: none`）となること。

## 4. 非機能要件 & 技術的制約

1. **Hello Elementor テーマ互換性**:
   - Elementor のビジュアルエディタ、および Header Footer Elementor プラグインとの干渉を起こさないこと。
2. **パフォーマンスへの影響**:
   - 追加する CSS は 3KB 未満とし、外部 JavaScript ライブラリ（jQuery等）を追加せず Vanilla CSS のみで実装すること。
3. **文字コード**:
   - すべての PHP / CSS ファイルは UTF-8 (BOMなし) で保存し、繁体字（Big5 / HKSCS）の文字化けを起こさないこと。
