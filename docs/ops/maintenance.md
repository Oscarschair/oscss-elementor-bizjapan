# 運用・保守手順書 (Operations & Maintenance)

## 1. 定常保守チェック

1. **WordPress Core / Elementor アップデート時**
   - ステージング環境でアップデート適用後、レイアウト崩れ（特にヘッダー・フッター・カスタムテンプレート）が発生していないか目視確認。
   - Elementor の「ツール」>「一般」>「CSSとデータの再生成」を実行。
2. **テーマコード変更時**
   - 変更後は必ず PC（1280px以上）および SP（375px〜414px）の実機/エミュレータで表示確認を実施。

---

## 2. トラブルシューティング

| 現象 | 原因候補 | 対処法 |
| :--- | :--- | :--- |
| Elementor 編集画面が読み込み中で停止する | メモリ制限またはプラグイン競合 | `wp-config.php` の `WP_MEMORY_LIMIT` を 256M 以上に引き上げる。他の拡張プラグインを一時停止して切り分け。 |
| スタイル変更が反映されない | ブラウザ・キャッシュプラグインのキャッシュ | キャッシュプラグイン（WP Rocket, LiteSpeed等）のキャッシュ消去、およびブラウザのハードリロード（Ctrl+F5）。 |
| ヘッダー/フッターが二重に表示される | Elementor Theme Builder とテーマ側の条件分岐競合 | `template-parts/header.php` での `elementor_theme_do_location()` 呼び出し条件を確認。 |
