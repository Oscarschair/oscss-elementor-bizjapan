# 0008. AI画像生成による古臭い画像の一新及び透過的自動置換フィルター導入の決定

- **ステータス**: 承認 (Accepted)
- **決定日**: 2026-09-09
- **決定者**: OSCSS 開発チーム

## 1. コンテキストと問題提起 (Context)
サイトの主要セクション（`e-con-inner` 配下）において、過去に配置された画像（後ろ姿の男性、木製積み木、粗いフローチャート画像）が極めて古臭く、香港の洗練された企業家層に対する訴求力・ブランド信頼感を著しく損ねていた。
一目でサービス内容が直感的に伝わり、ロイヤルブルーのメインカラーと調和するモダンな画像群への刷新が求められた。

## 2. 検討した選択肢 (Considered Options)
- **選択肢 1: AI画像生成による高品質3Dアイソメトリック画像作成 ＆ テーマ層での透過的自動置換フィルター（採用）**
  - メリット:
    - ブランドカラー（ロイヤルブルー・白）と一貫した、統一感のある最先端の3Dビジュアルを完全オリジナルで提供可能。
    - Elementor側のDBデータや管理画面を手動編集することなく、テーマの `the_content` フック経由で即時かつ安全に本番反映可能。
    - 各画像ファイルを Git リポジトリ配下（`assets/images/`）でバージョン管理可能。
  - デメリット:
    - 画像ファイルサイズが増加するため、適切な圧縮・WebP対応を将来的に検討。
- **選択肢 2: 商用ストックフォトサイトからの購入・手動差し替え**
  - デメリット: トーン＆マナーの統一が難しく、コストと作業工数がかかる。

## 3. 意思決定 (Decision)
**選択肢 1** を採用。
5枚の主要ビジュアル（会社設立、.jpドメイン、日語Web制作、ビザ・不動産、5ステップワークフロー図）を生成し、`assets/images/` に配備。テーマ側で自動置換する機構を導入した。

## 4. 結果と影響 (Consequences)
- **ポジティブな影響**:
  - 古臭い印象を完全払拭し、最先端かつ信頼性の高い日本進出パートナーとしてのブランドイメージを確立。
  - 5ステップのワークフロー図により、サービスの全体像が直感的に把握可能となった。
- **ネガティブな影響 / リスク**:
  - 特になし。
