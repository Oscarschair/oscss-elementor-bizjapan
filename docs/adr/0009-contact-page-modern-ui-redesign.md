# ADR-0009: お問い合わせページ（/contact-us/）全体のモダンUIリデザインと2カラム信頼レイアウトの導入

- **ステータス**: 承認済 (Accepted)
- **日付**: 2026-09-10
- **意思決定者**: OSCSS 開発チーム & Antigravity

---

## 1. 背景と課題 (Context & Problem Statement)

`/contact-us/` は、Google Forms から自社製フォームへの置換（ADR-0005）が行われたものの、ページ全体のデザイン・構成において以下の課題が残っていた：
1. **古いヒーロー画像**: 2024年2月の古いAI生成画像（Firefly製）が大きく表示され、モダンなビジネス代行サービスとしての鮮度と清潔感が不足していた。
2. **単調な1カラム配置**: ページ中央にフォームだけが孤立して配置されており、初見のユーザーに対する安心感・会社信頼情報・FAQが欠落していた。
3. **Elementorタグネストの歪み**: 旧Elementorページ上でGoogle Formsが埋め込まれていた見出しウィジェット（`<h2>`）の中にフォーム全体が包含され、HTML構文上不自然なネストが発生していた。
4. **見出しとリードコピーの不足**: 「聯絡我們」の直後に補足文がなく、ユーザーがどのような流れで回答を得られるかが不透明だった。

---

## 2. 検討した選択肢 (Options Considered)

1. **選択肢 A: Elementor の管理画面上でページレイアウトを手作業で再構築する**
   - デメリット: DB更新依存となり、Gitコード（Single Source of Truth）による完全自動デプロイと再現性が失われる。
2. **選択肢 B: テーマのPHP/CSSレイアウト層でクリーンに2カラム構成・動的置換・DOM正規化を行う（採用）**
   - メリット: Gitで100%管理可能。Google Formsの置換フック（`bizjapan_auto_replace_google_form`）内で、ヒーロー画像の刷新、H1下のリード文追加、見出しタグのアンラップ、および高信頼2カラムレイアウト（安心バッジ・会社情報・FAQ）を統合的に注入できる。

---

## 3. 決定内容 (Decision)

**選択肢 B** を採用し、以下のUI/UXリニューアルを実施する：

1. **ヒーロー画像の刷新**:
   - `generate_image` を活用し、東京タワー・最新オフィスデスク・.jpドメインと握手をモチーフにした最新3Dイラスト（ロイヤルブルー基調 `#0b57d0`）を生成・配備（`assets/images/contact-hero.jpg`）。
   - `the_content` フックで古いFirefly画像を自動置換。
2. **2カラム・高信頼グリッドレイアウトの導入**:
   - **上部信頼ストリップ**: 「1-2営業日返信」「NDA遵守」「広東語対応」「BUD/EMF基金支援」のピルバッジを配置。
   - **左カラム (380px)**: サービス特色カード、直接連絡先（`contact@oscarchair.jp`、営業時間、対応言語）、ミニFAQ。
   - **右カラム**: 入力フィールドと送信ボタン（ロイヤルブルーグラデーション）を備えた直感的なフォーム。
3. **モバイル完全レスポンシブ**:
   - 980px以下で縦積みに自動移行。フォームを優先配置し、余白・タップ領域（ボタン高さ52px以上）を最適化。
4. **DOM構造の正規化**:
   - `<h2>` タグ内に含まれる旧iframeコードを正規表現でスマートにアンラップし、W3C標準に準拠したセマンティック構造へ復元。

---

## 4. 影響と結果 (Consequences)

- **ポジティブな影響**:
  - ページ全体の信頼感・コンバージョン期待値が劇的に向上。
  - メール宛先（`contact@oscarchair.jp`）とロイヤルブルーのブランドカラーがサイト全体と完全に調和。
  - Gitリポジトリとデプロイスクリプトを通じた自動デプロイが維持される。
- **留意点**:
  - CSSアセットバージョンを `1.2.0` へ引き上げ、ブラウザキャッシュによる崩れを防止。
