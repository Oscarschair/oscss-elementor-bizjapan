# 0005. Googleフォームからテーマ内蔵自社製Webフォーム（青基調）への移行及び自動メール通知の決定

- **ステータス**: 承認 (Accepted)
- **決定日**: 2026-09-09
- **決定者**: OSCSS 開発チーム

## 1. コンテキストと問題提起 (Context)
`/contact-us/` ページにおいて、外部の Google フォーム（iframe）が使用されていたが、以下の課題があった：
1. サイト全体のブルー系デザインとの統一感がなく、チープな印象を与えていた。
2. モバイル閲覧時に iframe のスクロールやリサイズが不自然になり、離脱を招いていた。
3. 送信内容が `contact@oscarchair.jp` に直接かつスピーディーに届かず、顧客対応に遅れが生じるリスクがあった。

## 2. 検討した選択肢 (Considered Options)
- **選択肢 1: テーマ内蔵の自社製Webフォーム ＆ Googleフォーム自動置換（採用）**
  - メリット:
    - 外部プラグイン（Contact Form 7等）に依存せず、超軽量・高速に動作。
    - サイトのメインカラーである「青（#0b57d0）」に完全に合わせたプロフェッショナルなUI。
    - `wp_mail` を通じて `contact@oscarchair.jp` へ即時通知し、顧客への自動返信メール（zh-HK）も送信可能。
    - 万一Elementor側でiframeが残っていても、テーマ側フックで自動置換するため、即時本番反映可能。
- **選択肢 2: Contact Form 7 などのプラグイン導入**
  - デメリット: プラグイン更新保守が増え、デザインのCSS上書きが煩雑。
- **選択肢 3: Google フォームの継続利用**
  - デメリット: デザインの一貫性と通知即時性の課題が解決されない。

## 3. 意思決定 (Decision)
**選択肢 1** を採用。
`includes/bizjapan-contact-form.php` および `assets/css/bizjapan-contact-form.css` を実装し、ショートコード `[bizjapan_contact_form]` の提供と `/contact-us/` 内の Google フォーム iframe 自動置換を実装する。

## 4. 結果と影響 (Consequences)
- **ポジティブな影響**:
  - `contact@oscarchair.jp` へのリアルタイム確実なメール通知。
  - 青を基調とした高級感のあるフォームデザインによる CVR 改善。
  - スパム対策（Nonce + ハニーポット）によるセキュリティ確保。
- **ネガティブな影響 / リスク**:
  - サーバー（ロリポップ）の PHP `mail()` または SMTP 設定が正しく動作していることの確認が必要。
