# 0004. 香港市場に特化したモバイル固定 WhatsApp / 無料相談バー (Sticky CTA) 導入の決定

- **ステータス**: 承認 (Accepted)
- **決定日**: 2026-09-09
- **決定者**: OSCSS 開発チーム

## 1. コンテキストと問題提起 (Context)
香港におけるビジネス・商談のコミュニケーションチャネルは、Eメールよりも **WhatsApp** が圧倒的なシェアと即応性を持つ。
また、Webトラフィックの70%以上がスマートフォン経由であるにもかかわらず、従来のLPではページ最下部またはヘッダーの小さなリンクまでスクロールしなければ問い合わせできない構造となっており、コンバージョン（離脱防止）の大きな機会損失となっていた。

## 2. 検討した選択肢 (Considered Options)
- **選択肢 1: テーマ層での画面下部固定 Sticky CTA バー実装（採用）**
  - メリット:
    - スマホ幅（767px以下）でのみ常時表示され、常にユーザーの親指が届く位置に「WhatsApp 查詢」と「免費諮詢」を配置。
    - Elementor の個別ページ設定に依存せず、全ページ共通で安定して動作する。
    - CSSの `backdrop-filter: blur` を活用し、視認性とモダンなデザイン性を両立。
  - デメリット:
    - 最下部コンテンツが隠れないよう、`body` に `padding-bottom` を設ける配慮が必要。
- **選択肢 2: WhatsApp チャット用外部WordPressプラグインの導入**
  - メリット: プラグイン管理画面から設定可能。
  - デメリット: 余分なJS/CSSが読み込まれ、Core Web Vitals（表示速度）が低下する。また、プラグインの脆弱性リスクやアップデート保守が増加。
- **選択肢 3: 固定ボタンなし（従来のフォームのみ）**
  - デメリット: 問い合わせ率の改善が見込めない。

## 3. 意思決定 (Decision)
**選択肢 1** を採用。
テーマの `includes/bizjapan-seo-zhhk.php` の `wp_footer` フックと `assets/css/bizjapan-custom.css` により、プラグインなしで極めて軽量（Vanilla CSS）なモバイル固定コンバージョンバーを実装する。

## 4. 結果と影響 (Consequences)
- **ポジティブな影響**:
  - モバイルユーザーの問い合わせ心理的ハードルの劇的な低下（1タップで WhatsApp チャット開始）。
  - 軽量実装によるページ読み込み速度への悪影響ゼロ。
- **ネガティブな影響 / リスク**:
  - 画面最下部の要素と重ならないよう、レスポンシブ検証チェックリストでの確認を必須とする。
